# pyMSHBM

A BIDS-friendly Python implementation of the **Multi-Session Hierarchical Bayesian
Model (MS-HBM)** for individual cortical network mapping. This repository starts
from [Russell Poldrack's pyMSHBM](https://github.com/poldrack/pyMSHBM) and adds an
audited compatibility path for the executable
[Buckner lab PrecisionNetworkMapping workflow](https://github.com/bucknerlab/PrecisionNetworkMapping).

**Validation status:** the corrected optimizer is compared against executed,
pinned CBIG MATLAB source using Octave on reproducible synthetic fixtures.
Standard and missing-session fixtures agree on every network label and stopping
iteration within documented continuous-parameter tolerances. This is **not yet a
certification of whole-pipeline equivalence on real participant data in MATLAB**.
See [reference validation](docs/reference-validation.md) and the
[scientific contract](docs/scientific-contract.md).

## Install with uv

Python 3.11 or newer:

```bash
uv tool install 'git+https://github.com/lobennett/pyMSHBM.git'
pymshbm --help
```

The repository is private; Git must have permission to read it. For reproducible
analyses, install a specific commit by appending `@<commit>` to the Git URL.
No MATLAB, Octave or FreeSurfer executable is required for Python fitting.
Reference surface masks and DU15NET labels are required as data assets.

To develop or run from a clone:

```bash
git clone https://github.com/lobennett/pyMSHBM.git
cd pyMSHBM
uv sync --frozen --extra dev
uv run pymshbm --help
```

## Inputs

Pass a direct fMRIPrep derivative directory, or a BIDS root containing
`derivatives/fmriprep`. Select **fsaverage6 surface BOLD** (40,962 vertices per
hemisphere), generated by fMRIPrep with `--output-spaces fsaverage6`:

```text
fmriprep/
  sub-01/
    ses-01/func/
      sub-01_ses-01_task-rest_run-1_space-fsaverage6_hemi-L_bold.func.gii
      sub-01_ses-01_task-rest_run-1_space-fsaverage6_hemi-R_bold.func.gii
```

`space-fsaverage_den-41k` naming is also accepted. Each paired physical run
becomes one model session, following Buckner's wrapper. Multiple selected
participants are fitted jointly; changing the cohort can change an individual's
map. The default task is `rest`. Hemisphere pairing uses all filename entities;
ambiguous echoes, reconstructions, descriptions or surface representations are
rejected. Provide a directory with the intended single representation per run.

**Denoising must be decided before fitting.** fMRIPrep's surface outputs have not
received the residualization, band-pass filtering and smoothing implied by the
Buckner input filenames. This package performs no additional denoising,
censoring, smoothing or resampling. Use appropriately cleaned fsaverage6 BOLD
and preserve its BIDS entities to match your study's preprocessing protocol.
Raw-only BIDS, volumetric BOLD, fsnative, fsaverage5 and fsLR CIFTI receive an
actionable error. See [fMRIPrep's output documentation](https://fmriprep.org/en/stable/outputs.html).

## Prepare reference assets

Use the FreeSurfer subjects directory from the same preprocessing environment
(often `fmriprep/sourcedata/freesurfer`). It must contain
`fsaverage6/label/{lh,rh}.cortex.label`:

```bash
pymshbm-fetch-assets ./mshbm-assets \
  --freesurfer-dir /data/fmriprep/sourcedata/freesurfer
```

This downloads DU15NET labels and colors from a pinned Buckner commit, checks
their SHA-256 hashes, and records the supplied cortex-mask hashes. For offline
setup, add `--reference-dir /path/to/PrecisionNetworkMapping`. Assets remain
outside the Python distribution; their original terms and attribution apply.
Changing FreeSurfer masks may change the seed set and results; identical
preprocessing and masks are necessary for a strict reference comparison.

## Inspect and run

```bash
# Show precisely which files and model sessions will be used; writes nothing.
pymshbm bids /data/bids /data/derivatives/pymshbm \
  --participant-label 01 02 --task rest --dry-run

# Fit all selected runs and write a new derivative dataset.
pymshbm bids /data/bids /data/derivatives/pymshbm \
  --assets-dir ./mshbm-assets --participant-label 01 02
```

`--session-label` and `--run-label` select additional subsets. `--max-iter 5`
is the upstream outer-iteration limit; reaching it does not establish optimizer
convergence. An existing output directory is never overwritten. Numerical
nonconvergence or invalid data fails without publishing a completed dataset.

The profile tensor is stored temporarily on disk in float32. Its size is
`81924 × number_of_cortical_seeds × subjects × maximum_runs × 4` bytes, roughly
0.36 GiB per subject/run slot for 1,175 seeds, plus working memory and outputs.
Unequal session counts still allocate rectangular storage. Use a local work
disk with adequate free space and control BLAS threads with your platform's
usual environment variables when running on a cluster.

## Outputs

```text
pymshbm/
  dataset_description.json
  provenance.json
  model/priors/Params_Final.mat
  model/ind_parcellation/...
  sub-01/func/
    sub-01_space-fsaverage6_atlas-DU15NET_hemi-L_dseg.label.gii
    sub-01_space-fsaverage6_atlas-DU15NET_hemi-R_dseg.label.gii
    ...JSON sidecars and posterior NPZ...
```

Labels preserve DU15NET IDs and colors (1–15; zero is medial wall/unassigned).
Provenance contains input paths and hashes, subject/run mapping, software and
asset versions, exact model settings, objective history and iteration-limit
status. GIFTI derivatives use BIDS-style names; `.bidsignore` identifies the
additional model and posterior artifacts. This is not a general BIDS validator.

## Scientific behavior

The compatibility path samples seed vertices (no ROI averaging), computes
Pearson correlations, applies one global top-10% binary threshold across both
hemispheres, initializes from DU15NET labels, and follows CBIG's profile
centering, precision, nested EM and stopping rules. It extracts individual
labels from the group-estimation posterior. It does not add k-means
initialization or a second MRF individual fit.

The inherited `pymshbm-wrapper`, `pymshbm-extract-results`, individual MRF,
group-training APIs and cerebellar utilities remain available. **They are
legacy/experimental paths, not covered by the new whole-workflow compatibility
contract.** The group-estimation engine is corrected for all callers.
The inherited [pipeline guide](docs/pipeline_guide.md) documents that older path.

## Tests and reference reproduction

```bash
uv run --frozen pytest -q
uv build
uv run python validation/compare_reference.py
uv run python validation/compare_reference.py --case missing
```

Ordinary tests use checked-in outputs generated by upstream code, requiring
no Octave installation. [Validation instructions](validation/README.md) explain
how to regenerate the independent reference. Source checksums and measured
per-field errors accompany the fixtures. A full-size synthetic file/pipeline
smoke test is available in `validation/run_surface_smoke.py`.
